# Intelligence Seed 001 — v0.2.0

Protocol-neutral intellectual artifact designed for independent human or machine evaluation.

## Changes in v0.2.0
- Controlled operational definitions
- Evidence record structure and citation slots
- Explicit evaluation protocol and falsifiability prompts
- Machine-readable response and descendant schemas
- Discovery manifest for indexing and retrieval
- Stronger provenance, integrity, and lineage guidance
- Clear separation between the seed and any agent that may host or discover it

## How to evaluate
1. Read `seed.json` and `seed.md`.
2. Review definitions and identify ambiguity.
3. Add evidence and counter-evidence to a separate response.
4. Verify hashes in `manifest.json`.
5. Never silently edit this release; place critiques in `responses/` and revisions in `descendants/`.

**Design principle:** optimize for independent evaluation, not persuasion.
